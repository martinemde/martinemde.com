> Prime Agent is an open-source coding and research agent for general and long-running work. It is designed around two core abstractions:
>
> - The Recursive Language Model (RLM) treats context as variables (prompt-as-a-variable) and tools like recursive subagents as function calls (programmatic tool /sub-agent calling) inside a persistent REPL.
> - The Continual Harness stores supplemental prompts, memories, skill descriptions, and reusable subagent specifications as durable state that Prime Agent can refine through small, evidence-backed updates, local to the session by default.

It's nice to find refreshing approaches in a space where everyone is copying each other. [Prime Agent](https://github.com/PrimeIntellect-ai/prime-agent) feels like an evolution of the coding agent harness and it seems to work really well. Watching it continuously write code to solve coding tasks, and then reuse that code to develop its capabilities, is refreshing. It seems to accomplish in one block of code what a typical agent does in 5 or more tool calls. For example, making a PR will often be 1 chunk of python, not 5 tool calls to push the code, write a description file, call gh, check if it worked, etc. Like I said: refreshing.

These agents are so good at writing code that making all of their work into code is a logical step. Tool calls are just a different shape of code, so why not make it all one? I'm impressed.
